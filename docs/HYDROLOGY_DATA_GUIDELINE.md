# Hydrology Data Guideline

本文件規範水位與雨量的來源、時間、缺測、判讀與路線關聯。目標是讓使用者理解資料，不把單一測站數值誤認為安全結論。

## 資料來源

### 水位

- 測站清單：`src/data/water-stations.json`。
- 即時值：水利署 WRA 即時 API。
- 歷史值：PocketBase `water_level_observations`。
- 收集排程：GitHub Actions 每 3 小時一次，於 UTC 小時的第 17 分執行。
- 保留期：90 日。

### 紐西蘭西岸水位／流量（WCRC）

- 測站清單：`src/data/nz-water-stations.json`，2026-09-29 從 WCRC 公開河川地圖整理 52 站，保留各站 ESNZ／TDC／Manawa Energy 等名稱標示。
- API：`/api/nz/water-level/[stationId]?days=1|7|14&metric=level|flow`；站號以 `wcrc:` 區別 WRA。
- 即時值：WCRC `dashboards/overview/map_river_level.php`；保留水位與流量各自的觀測時間，通訊中斷文字視為缺測。
- 歷史值：WCRC `dashboards/riverlevels/highcharts_data.php` 的 `riversdata` JSON；明確指定 `type=Level|Flow` 並驗證回傳項目。`highstock.php` 頁面可能忽略所選項目，不用它解析河川資料。
- 無新增蒐集排程或資料庫寫入；伺服器快取 5 分鐘。近 7／14 天為向前 7／14 × 24 小時的查詢範圍；上游最後觀測不一定與即時地圖一致。
- 歷史 Unix 毫秒直接轉 ISO；地圖當地時間依 `Pacific/Auckland`（包含夏令時間）轉 ISO，UI 以紐西蘭時間及完整年份顯示。
- 水位可為負數（測站基準），流量不得為負；缺值保留 `null`，歷史折線不跨缺值連線，最新缺測不以舊值替代。
- 未匯入警戒門檻，不標示「正常／安全」；超過 3 小時的有效觀測明示資料可能延遲，這是本產品的提示門檻。
- 官方來源：https://www.wcrc.govt.nz/environment/water/river-levels-rainfall 。WCRC 說明網頁資料為尚未完整檢核的原始觀測；測站卡顯示來源與原始資料連結。
- 驗證：`node tests/api/nz/water-level/wcrc.test.mjs`。

### 雨量

- 測站清單：`src/data/rainfall-stations.json`。
- 即時值：CWA API，經 `/api/cwa/rainfall/[stationId]`。
- 7／14 日歷史：CWA API，經 `/api/cwa/rainfall-history/[stationId]`。
- 歷史日資料缺測時保留 `null`，不得補成 `0`。

### 台灣今日累積雨量圖層

- 來源：CWA `O-A0040-003`（去背景小間距日累積雨量圖），公開 S3 KMZ，不需 API key；經 `/api/cwa/rainfall-map` 解出 PNG、四角經緯度與觀測時間，伺服器快取 10 分鐘。
- 範圍為台灣時間當日 00:00 至觀測時間；00:00 那一版是前一日整日累積，API 起點改為前一日 00:00，UI 標為「昨日」。圖例標示完整日期與時間，超過 3 小時未更新時提示可能延遲。
- 色階採 CWA 小間距級距（1／2／6／10／15／20／30／40／50／70／90／110／130／150／200／300 mm），與 `O-A0040-002` 圖例一致；上游改色階時同步更新 `src/lib/rainfallMap.ts`。
- 原圖為經緯度等距，前端先轉為 Web Mercator 再疊圖，否則台灣中部約偏 2 km。
- 圖例與圖層列顯示「今日最大累積」級距（由圖上像素判讀）；全圖無色時明示「今日尚未測得降雨」，避免使用者誤以為圖層故障。圖例放在地圖可見區左上角（緊貼側欄，跟著側欄開合移動），避開右側的圖層面板、路線 Panel，以及底部置中的工具列、篩選 chips 和提示；圖例與圖層面板分居左上、右上，可同時開啟。手機版圖例放在工具列上方、全寬，會被圖層面板蓋到，所以只有手機在面板開著時收起圖例。圖例右上角的關閉鈕會把雨量圖切到「關」。
- 取得失敗時移除圖層並顯示重試，不保留舊圖。僅台灣顯示；預設關閉，模式（`off`／`today`／`past48`／`past72`／`qpf6`／`qpf12`）存於 `rainfall-map-tw`。雨量圖一次只顯示一種模式。
- 分享：目前畫面上的模式寫入網址 `?rain=today|past48|past72|qpf6|qpf12`（關閉或在紐西蘭時移除）；開啟連結時網址優先於 `rainfall-map-tw`。連結帶 `qpf6`／`qpf12` 但不在颱風警報期間時，開啟對應時距的氣象署預報圖卡片；只有網址會觸發這個動作，偏好還原與定時更新不會自動彈出卡片。
- 驗證：`node tests/api/cwa/rainfall-map.test.mjs`。

### 台灣近 48／72 小時累積雨量（雨量站）

- CWA Open Data 沒有多日累積圖層：觀測目錄中與雨量有關的只有日累積圖（`O-A0040-001`～`-004`，皆只有最新一版）、1 小時雷達估計（`O-B0045-001`）與測站資料。網站的 2～5 日累積圖是加了底圖的 JPG 且有防爬蟲，不使用。
- 因此用與氣象署日累積圖相同的作法自行重建：`O-A0040-004` 本身就是雨量站累積值以距離權重法內插到 0.03° 網格。來源為 CWA `O-A0002-001` 公開 S3 JSON（全台約 1,340 站，不需 API key）的 `Past2days`／`Past3days`。
- `/api/cwa/rainfall-map?kind=stations` 在伺服器內插（每格取最近 8 站、權重 1/d²；測站所在格直接用實測值），輸出與 `O-A0040-004` 相同的 67×120 網格（南→北、西→東，海面 `null`），伺服器快取 10 分鐘。併入既有 function、不新增檔案（Vercel Hobby 12 個 Functions 上限）。
- 陸地遮罩 `src/data/cwa-grid-land-mask.json` 取自同網格的溫度圖 `O-A0038-003`（海面為 `-999`）。不可用 `O-A0040-004` 當遮罩：它的海面是 `0`、乾燥陸地是 `-1`，部分陸地格又是 `0`，會破洞。
- `Past2days`／`Past3days` 是到觀測時間為止的滾動 48／72 小時，不是日曆日；UI 一律寫「近 48／72 小時」並標出起訖時間，不得寫成「昨日」「前日」。
- 比最新觀測落後 3 小時以上的測站不參與內插（離線測站會保留舊累積值）；無效值為 `null`。未達 1 mm 的格點不著色，與今日累積圖一致。圖例摘要引用「單站最大」實測值，不引用內插峰值；來源說明註明測站之間為估計值。
- 驗證：`node tests/api/cwa/rainfall-map.test.mjs`。

### 台灣降雨預報

- 「預報 6h／12h」是唯一入口：有颱風格點（`active: true`）時疊在地圖上；其他時間（含尚未確認或確認失敗）開啟對應時距的官網預報圖卡片，並關閉地圖上的雨量圖層（所有模式互斥，卡片開著時選取狀態落在對應的預報按鈕），不再另設「氣象署 6／12 小時預報圖」連結。
- 平時：CWA 官網定量降水預報圖 `QPF_ChFcstPrecip_6_06／6_12／12_12／12_24.png`，於卡片中顯示原圖（含發布與有效時間），不疊到地圖上；原圖帶底圖與圖例、無地理座標。
- 颱風期間：CWA `F-C0041-001／002`（陸上颱風警報期間定量降水格點預報，130×130、TWD67），經 `/api/cwa/qpf-grid`，需 `CWA_API_KEY`，快取 10 分鐘。6h 用第 1 時段，12h 為第 1＋2 時段相加，任一缺值即缺值。
- 平時 CWA 仍保留最後一期格點；第 1 時段結束後 API 回 `active: false`，不得把舊預報當成目前預報。
- 實際檔案把 16 900 個值放在同一行（與規格書的 130 行不同），parser 以值的數量驗證。負值視為缺值。
- 預報色階為 0.5／1／2／5／10…mm（與觀測的 1／2／6 不同），見 `QPF_SCALE`。TWD67 與 WGS84 約差 0.8 km，小於 5 km 格距，目前不做轉換。
- 驗證：`node tests/api/cwa/qpf-grid.test.mjs`。

## 時間規則

- 顯示觀測時間，不用請求時間冒充更新時間。
- WRA 無 offset 的時間按台灣時間 `UTC+08:00` 解讀，DB 統一存 ISO 8601。
- UI 日期必須包含年份；歷史圖表以台灣日曆日切分。
- 「近 7 天／14 天」指日曆範圍，不保證每天都有資料。
- 資料不足時明寫「目前取得 N 日」，缺測日顯示 `—`。

## 空值與異常值

- 真正觀測到的零才顯示 `0`。
- `null`、空字串、非數字、負雨量與 WRA sentinel `-999999` 都視為缺測。
- 水位收集只接受已知測站、有效 `checkresult`、合理時間與合理水位。
- 地址未知時留空，不顯示 `0`。
- API 失敗顯示來源、問題與重試，不保留看似即時的舊值。

## 水位判讀

水位只與該站公布的警戒值比較：

| Tone | 條件 |
|---|---|
| `danger` | 達第一警戒。 |
| `warning` | 達第二警戒。 |
| `watch` | 達第三警戒。 |
| `normal` | 有門檻且低於所有警戒。 |
| `no-threshold` | 有數值但測站未設定警戒。 |
| `muted` | 缺測或無效值。 |

沒有警戒門檻不能顯示為「正常」。Tone 必須同時顯示文字與實際數值，不能只靠顏色。

## 雨量判讀

目前 UI 的資料提示門檻：

| Tone | 條件 |
|---|---|
| `danger` | 24 小時 ≥ 200 mm，或 3 小時 ≥ 100 mm。 |
| `warning` | 24 小時 ≥ 80 mm，或 1 小時 ≥ 40 mm。 |
| `watch` | 3 日累積 ≥ 40 mm。 |
| `normal` | 上述必要資料完整且未達門檻。 |
| `muted` | 1、3、24 小時或 3 日資料任一不足。 |

提示文字只能描述雨量與可能影響，例如「累積雨量偏高」；不得只憑此資料宣稱路線安全或危險。

## 路線與測站關聯

- 距離以入溪 GPS 加 GPX 取樣點計算，不只看路線名稱或行政區。
- 鄰近水位站上限為 5 km；超過通常屬不同水系，不呈現在路線摘要。
- 鄰近雨量站目前上限為 20 km。
- 最近測站仍可能位於不同流域；UI 必須標示「距路線」，不能暗示測站代表整條溪。
- 搜尋命中的測站即使 layer 關閉也必須顯示。
- 路線叫出的測站與目前選取測站不可縮回 cluster，直到詳情關閉。

## UI 規則

- TW／NZ 的水位／雨量圖層預設關閉，兩國選擇分別保存在瀏覽器；點開路線不得自動開啟。
- 每次進入水文 tab，暫時開啟水位／雨量並隱藏路線，圖層開關同步且可操作；離開時恢復原本的路線及各國水文圖層設定，不將暫時選擇寫入偏好。
- 水文 tab 沿用剛才瀏覽的國家，提供台灣／紐西蘭切換；清單列出該國測站，仍可從清單直接查看單站。
- 水文國家以 `?view=hydrology&country=tw|nz` 保留；明確的測站搜尋結果不受一般圖層開關影響，也不覆寫圖層偏好。
- 水位與雨量卡都顯示站名、位置、主要數值、判讀、時間序列、更新時間與來源。
- 圖表必須有 X/Y 軸名稱、年份與單位。
- 測站卡靠近對應 icon，定位完成前不要先顯示分離的箭頭。
- 卡片距手機四邊至少 12px，且不能阻擋 Sidebar 與地圖操作。
- 雨量歷史下載格式固定為 PNG，按鈕需標明格式。

## 收集與故障處理

- 相同 `station_id + observed_at` 不重複寫入。
- 一次排程失敗不得刪除既有歷史。
- 上游回傳空陣列或全部無效時，排程應失敗並留下紀錄。
- 改動 parser、時區或門檻後，至少執行相對應的小型測試與正式 build。
- 變更資料來源、收集頻率或保留期時，同步更新本文件與 UI 資料來源說明。
