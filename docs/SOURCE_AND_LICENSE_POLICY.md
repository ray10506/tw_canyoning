# Source and License Policy

本政策適用於路線文字、GPX、照片、手繪 topo、PDF、影片、政府開放資料與第三方網站內容。

## 基本原則

- 公開網址與署名不等於取得複製、修改或重新散布權。
- 只收錄完成產品功能所需的最少內容。
- 無法確認授權時，只保留來源連結與自行撰寫的事實摘要。
- 不移除浮水印、作者名稱、授權文字或必要 attribution。
- 收到下架要求時先停止公開該資產，再確認權利與後續處理。

## 內容分類

| 類型 | 預設處理 |
|---|---|
| 事實資料 | 可自行整理成新的摘要，但保留來源並避免大段照抄。 |
| GPX | 需原作者或授權條款允許重新散布；否則只放原始下載頁。 |
| 照片 | 需明確允許本網站使用；每條路線最多四張代表照片。 |
| Topo／PDF 頁面 | 需明確允許重製；只保留進場 map 與必要手繪路線圖。 |
| YouTube／Vimeo | 保存外部連結或官方 embed，不下載重傳影片。 |
| 政府開放資料 | 依該資料集使用條款保存來源、資料集名稱與更新時間。 |
| 地圖／圖磚 | 遵守服務條款與畫面 attribution，不擷取後當成自有底圖。 |

## 每個來源應記錄

- 原始頁面或下載網址。
- 作者／機構。
- 取得日期與資料日期。
- 授權名稱、條款網址或書面同意紀錄。
- 允許的用途：連結、顯示、修改、下載或重新散布。
- 本專案實際使用的檔案與轉換方式。

目前沒有獨立 attribution collection 時，路線來源先記在 `note`、`source_url` 或匯入 review 紀錄；不要因此省略來源。

## 使用決策

### 可以直接使用

- 專案自行產生且不包含第三方受保護內容的資料。
- 條款明確允許本用途的開放資料，並完成要求的 attribution。
- 作者明確授權網站重製／展示的檔案。

### 只保留外部連結

- 頁面公開但沒有再利用授權。
- GPX 可下載但未說明能否重新散布。
- 照片、PDF、topo 或影片的權利狀態不明。

### 不使用

- 明確禁止重製、商業使用或修改，而本專案用途不符合。
- 無法辨識作者或來源。
- 檔案包含私人位置、聯絡資料或其他不應公開的敏感資訊。

## 摘要與引用

- 用自己的結構與文字整理路線事實，不逐段翻譯或重製原文。
- 短引文只有在原句本身重要時使用，並附作者與來源。
- 不把單次探訪回報改寫成永久事實；保留日期與回報者。
- 安全、固定點與水況資訊必須保留觀測日期。

## GPX 與媒體處理

- 保存原始檔與處理後檔案的對應關係，但原始檔不一定公開。
- GPX 發布前移除與導航無關的個資與裝置資料。
- 圖片轉檔不得移除 attribution；不得為提速而降低到無法閱讀 topo。
- 代表照片採 lazy loading，最多四張；影片只存連結。
- 同一照片不要同時放入代表照片與原始路線圖。

## Review checklist

- [ ] 來源與作者可辨識。
- [ ] 授權涵蓋實際使用方式。
- [ ] 必要 attribution 已出現在 UI 或資料來源區。
- [ ] 沒有未授權下載重放的 GPX、照片、topo 或 PDF 頁面。
- [ ] 摘要不是大段改寫或翻譯原文。
- [ ] 圖片數量、分類與尺寸符合路線 SOP。
- [ ] 外部連結仍可開啟正確內容。
